接口文档

OpenAI 兼容。Base URL 后面接 /v1，鉴权用站点发的 sk-wb-…。

鉴权

Authorization: Bearer sk-wb-xxxxxxxx

也接受 x-api-key 头。Key 只在创建时显示一次，服务端只存哈希。

端点

方法与路径说明
POST /v1/chat/completions对话补全，支持 stream:true（SSE 原样透传）
GET /v1/models模型目录
GET /healthz站点存活探针

流式对话

curl -N {{.Upstream}}/v1/chat/completions \
  -H "Authorization: Bearer sk-wb-..." \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-v4-flash","messages":[{"role":"user","content":"你好"}],"stream":true}'

Python

from openai import OpenAI

client = OpenAI(base_url="{{.Upstream}}/v1", api_key="sk-wb-...")
for chunk in client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "你好"}],
    stream=True,
):
    print(chunk.choices[0].delta.content or "", end="")

Node.js

import OpenAI from "openai";

const client = new OpenAI({ baseURL: "{{.Upstream}}/v1", apiKey: "sk-wb-..." });
const r = await client.chat.completions.create({
  model: "deepseek-v4-flash",
  messages: [{ role: "user", content: "你好" }],
});
console.log(r.choices[0].message.content);

计量与限流

  • 按上游返回的 usage.total_tokens 计入额度；流式取最后一个 usage 帧。
  • 额度用完返回 429 quota_exceeded。
  • 请求记录（模型、token、耗时、来源 IP）在控制台「最近请求」里可查。
